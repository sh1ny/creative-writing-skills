Use the cw-novel-init skill to set up a new novel project.

Steps:
1. Confirm where to create the vault (project root or subfolder)
2. Ask for title, genre, and premise (2-3 sentences)
3. Ask if they have a structure template — if not, present the curated menu (Save the Cat, Story Grid, Hero's Journey, Three-Act, Four-Act, Seven-Point, Freytag's Pyramid)
4. Create the complete vault scaffold with all folders and starter files
5. Generate a first-draft logline from their premise
6. Tell user what was created and suggest next step: /pitch to develop the premise further

> **Agent tip:** Use the `cw-write` primary agent.
