Use the cw-beat skill to write prose for a specific beat in a scene.

Context loading (minimal — do not load more than this):
- The beat description from the scene outline
- Full scene outline (metadata + all beats listed)
- Chapter outline (scene summaries only — NOT prose)
- Relevant Codex entries: characters in scene + scene location
- Style/master.md style guide
- Last ~500 words of previous scene (if exists)

After writing each beat:
- Append it to Story/Chapters/[Act]/[Chapter]/[Scene].md
- Mark beat as written in the outline
- Ask: write next beat, regenerate this beat, or done?
